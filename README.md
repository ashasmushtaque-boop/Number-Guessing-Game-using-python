# 🎯 Number Guessing Game (Python)

A simple beginner-friendly Python project where the computer randomly selects a number, and the user has to guess it correctly. The game continues until the correct number is guessed.

---

## 🚀 Project Description

This is a **command-line based Number Guessing Game** built using Python. The program generates a random number between 1 and 10, and the user keeps guessing until they find the correct number.

It is a great project for beginners to understand:
- Loops
- Conditional statements
- User input
- Random number generation
